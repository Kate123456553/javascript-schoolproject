1. Was ist JavaScript?

JavaScript ist eine Programmiersprache zur Erstellung von Websites, die zusammen mit html- und css-Codes verwendet wird.

Während html-Codes für den reinen Text, die Infos und Ähnliches auf der Website zuständig sind und ein css-Code das ganze dann mithilfe von Farben, unterschiedlichen Schriftarten und Ähnlichem verschönert, kümmert sich der JavaScript-Part um die Funktionen und Aktionen der Website.

Damit ist gemeint, dass man beispielsweise Buttons betätigen kann und dann eine Funktion ausgeführt wird.

2. Variablen

Variablen sind dafür da bestimmte Informationen unter einer Art Name, also der Variable, zu speichern.
Zum Beispiel könnte die Variable, wie im folgenden Beispiel "name" heißen. Die dazugehörige Information wäre dann zum Beispiel "Herbert". 

let name = "Herbert";
let alter = 16;
const geburtsort = "Berlin";

Eine Variable wird entweder mit dem Begriff "let" oder "const" angekündigt.
"let" wird verwendet, wenn die Variable sich ändern könnte. Wie zum Beispiel beim Alter. Herbert wird schließlich nicht für immer 16 Jahre alt bleiben.
"const" wird stattdessen immer dann verwendet, wenn sich die Information, oder der Wert, hinter der Variable sicher nicht mehr verändern wird. Dann ist der Wert sicher festgelegt. Beispielsweise beim Geburtsort. Dieser ist festgelegt.

Diese Variablen kann man dann zum Beispiel in einen Text einfügen. Das ist dann besonders praktisch bei solchen, die sich verändern könnten. Dann muss man nicht den ganzen Text jedesmal umschreiben, sondern es ist beispielsweise einfach festegelegt, dass sich die Variable "alter" jedes Jahr um 1 erhöht.

3. Bedingungen

Mithilfe von "if" und "else" kann man Bedingungen in ein Programm einfügen. Also dass etwas nur passiert, wenn eine bestimmte Kriterie erfüllt ist. Andernfalls wird eine andere Aktion ausgeführt.

Wie man sich bestimmt schon herleiten kann, wird mit "if" die Bedingung angekündigt. Danach erklärt man dem Programm, wie es sich in diesem Fall verhalten soll. Nach "else" erklärt man die alternative Aktion.

Im folgenden Beispiel bedeutet das, dass wenn das oben angegebene Alter von Herbert mindestens 18 ist, der Satz "Herbert bist volljährig." ausgegeben wird. Die Alternative ist, wenn die Bedingung nicht erfüllt ist, dass der Satz "Herbert bist noch minderjährig." erscheint.
Da Herbert erst 16 ist, wird der zweite Satz erscheinen.

Um den Satz anzeigen zu lassen, werden wir den alert-Befehl nutzen. Diser ist leicht zu verstehen und anzuwenden. "alert()" lässt eine Meldung aufploppen. In die Klammern schreibt man dann den Inhalt dieser Meldung. Dieser muss in Anführungszeichen stehen. 

if (alter >= 18) {
    alert("Herbert ist volljährig.");
} else {
    alert("Herbert ist noch minderjährig.")
}

4. Funktionen

Funktionen erklären eigentlich nur eine bestimmte Aktion.
Also wenn beispielsweise auf einen Knopf gedrückt wird, soll eine Aktion ausgeführt werden.
Doch könnte es sein, dass dieselbe Aktion bei mehreren Buttons ausgeführt werden soll, dann bietet es sich eben an, eine Funktion zu verwenden.

In dieser erklärt man dann den ablauf der Aktion. Und anstatt, dass man nun für jeden Knopf die Aktion beschreiben muss, verweist man einfach auf die Funktion. Das erspart einiges an Arbeit.

In einem Code wird eine Funktion mit "function" angekündigt. Direkt danach nennt mann den Namen der Funktion, wie in diesem Beispiel "begruessung". In die darauf folgenden Klammern könnte man theoretisch noch Parameter einfügen, aber die brauchen wir in diesem Beispiel nicht. An die Klammern musss man jedoch trotzdem denken. Danach kommen die geschwungenen Klammern. In diesen wird die Aktion beschrieben.
In diesem Fall ist es wieder ein alert-Befehl. 

function begruessung() {
    alert("Hallo! Schön, dass du hier bist.");
}

5. Ein eigener kleiner Code

Deine Aufgabe ist es einen kleinen JavaScript-Code zu schreiben, bei dem eine Zahl erraten werden soll. Da wir hierfür weder einen html-Code, noch css-Code brauchen, bietet sich das sehr gut an.
Es wird so ablaufen, dass man nach einer Zahl gefragt wird und anschließend eine Rückmeldung kriegt, ob es die gesuchte Zahl ist oder nicht.
Arbeite am besten einfach die folgenden Punkte ab.

Aufgabenstellung:

  1. Lege die erste Variable an. Die geheime Zahl, die erraten werden soll. Den Wert dieser kannst du dir frei überlegen.
  2. Bei der zweiten Variable wird es sich um die Zahl handeln, die geraten wird. Lege dafür wie gewohnt eine Variable an und gebe ihr einen Namen. Aber nun gibst du anstatt einer Zahl einen Befehl ein, den wir bisher noch nicht kennen. Anstatt der Zahl gibst du ein: prompt("..."). Nur an Stelle der drei Punkte überlegst du dir eine Fragestellung, die nach der geratenen Zahl fragt.
  3. Erstelle eine Funktion. Diese wird dann die eingegebene Zahl überprüfen. Daher bietet sich zum beispiel der Name "pruefen" an. Der Inhalt dieser Funktion wird im folgenden Schritt erklärt.
  4. Nun brauchen wir eine if/else-Bedingung. Fangen wir mit if an. Die Bedingung die erfüllt sein muss, ist, dass die Zahlen gleich groß sind. Also geben wir die beiden Variablen ein, mit zwei "=" voneinander getrennt.
  5. Nun musst du noch sowohl für die if- als auch else-Bedingung mitteilen, was dann passieren soll. In diesem Fall bietet sich der alert-Befehl an, den ich weiter oben bereits erklärt habe. Schreibe diesen einfach in die geschwungenen Klammern und gebe sinnvolle Rückmeldungen ein. einmal für ein richtiges Ergebnis und dann nochmal für ein falsches Ergebnis.
  6. Als allerletztes musst du dem Programm natürlich noch sagen, dass es die Funktion auch ausführen soll. Dafür schreibst du einfach in eine neue Zeile den Namen der Funktion und die Klammern (). Jetzt nurnoch mit dem Button deinen Code ausführen, und es sollte funktionieren.
