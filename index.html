Grundlagen Variablen Bedingungen Funktionen

1. Was ist JavaScript?

JavaScript ist eine Programmiersprache. Sie macht Websites interaktiv. Zum Beispiel können Buttons auf Klicks reagieren.

2. Variablen

Variablen speichern Informationen, zum Beispiel Texte oder Zahlen. 

let name = "Max";
let alter = 16;
const land = "Deutschland";

let erlaubt es, einen Wert zu ändern. const ist für eine Variable gedacht, deren Zuweisung nicht geändert werden soll.

3. Bedingungen

Mit if und else kann ein Programm unterschiedliche Entscheidungen treffen. 

if (alter >= 18) {
    // Person ist volljährig
} else {
    // Person ist minderjährig
}

4. Funktionen und Klick-Zähler

Funktionen sind Code-Blöcke, die man aufrufen kann, wenn man sie braucht. 

function begruessung() {
    alert("Hallo!");
}
